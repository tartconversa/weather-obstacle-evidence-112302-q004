# 资料契约

本目录只含本地合成记录，不包含真实驾驶员、车辆或道路资料。新闻报道描述的是厂商发布信息及公开说明，不是本资料集中的实测结论。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `weather.csv` | `station_id`, `region`, `observed_at`, `rain_mm`, `visibility_km`, `station_coverage` | 47 |
| `drives.csv` | `trip_id`, `version`, `vehicle_id`, `region`, `started_at`, `ended_at`, `sensor_config`, `upload_fraction` | 50 |
| `obstacles.csv` | `obstacle_id`, `trip_id`, `frame_start`, `frame_end`, `type`, `review_state`, `outcome` | 30 |
| `test_windows.csv` | `window_id`, `region`, `route_id`, `forecast`, `permit`, `sensor_config`, `capacity`, `status` | 24 |

输入文件之间通过明确的标识字段关联。记录时间均为 UTC 或 ISO 日期。缺失覆盖、待复核和撤回状态是有效业务事实，不能自动解释为零事件或成功。事件标签、回执、版本和授权范围以各行记录为准。所有示例数值由固定种子构造，仅供本地数据流程开发与测试。
